SchrödingersCAT

An open-source CAT tool that never loses your work.

SchrödingersCAT is a computer-assisted translation tool for Windows, Linux and macOS. It opens XLIFF files, shows source and target side by side, and helps with translation memory, terminology and quality checks, with a keyboard workflow close to memoQ's.

Early development. It's usable for real XLIFF 2 jobs, but expect rough edges, and keep a copy of important files.

Download Source code on GitHub

Features

Lossless XLIFF

  • Reads and writes XLIFF 2.0, 2.1 and 2.2: files, groups, units, segments, notes and segment states.
  • Inline codes, annotations, extensions and modules round-trip intact.
  • Never silently drops data: content it can't represent is refused with a clear error, before anything is written.
  • Saves atomically, so a failed save never leaves a half-written file.

The editor

  • Inline codes are shown as chips. Protected codes can't be deleted, and copies follow XLIFF's editing hints.
  • A code check runs as you type and marks missing, unknown, unpaired or reordered codes.
  • F9 inserts the next missing code, Ctrl+Insert copies the source, Ctrl+Enter confirms and moves on.

Translation memory

  • Fuzzy matches with the differences from the current source marked; codes are carried over when you insert one.
  • Exact matches fill empty targets automatically, and confirmed segments are stored straight away.
  • Concordance search (Ctrl+K) that matches word beginnings, so suffixed forms are found too.
  • TMX import and export, and a window for editing and cleaning up entries.

Terminology

  • A termbase with the terms found in the current segment marked in the source.
  • Ctrl+T picks a term translation to insert, Ctrl+E adds a new term from the selection.
  • TBX and CSV import and export.

Quality checks

  • Numbers, untranslated segments, targets identical to the source, text marked not to translate, and repeated words.
  • Terminology: terms not translated as the termbase or glossary says, and forbidden translations.
  • Inconsistent translations across the document, whitespace, end punctuation and unpaired brackets or quotes.

Download

Builds for Windows, Linux and macOS (Intel and Apple silicon) are on the releases page. They include .NET, so there's nothing else to install: unzip and run SchrodingersCat.App.

The builds aren't signed yet, so Windows SmartScreen and macOS Gatekeeper warn the first time. On macOS, run xattr -dr com.apple.quarantine SchrodingersCat on the unzipped folder first.

Open source

SchrödingersCAT is written in C# on .NET with Avalonia, and released under the MIT license. Bug reports and ideas are welcome as GitHub issues.
